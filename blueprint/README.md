# Blueprint Directory

This directory contains the consolidated machine-design blueprint for The Byzantine Shadow.

## Primary artifact

`SHADOWBYZANTINE_BLUEPRINT_v0.3.md`

It defines the donor-traceable models, purposes, Shadow code references, evidence classes, reconstruction boundaries, Byzantine adaptation boundaries, implementation gates, and definition of done.

The blueprint is intentionally consolidated: future work should update this artifact and the existing forensic ledgers rather than proliferating parallel architecture documents.

## Evidence rule

The blueprint is subordinate to the canonical donor `ShadowSource.per`, the source-authentication chain, current forensic extraction, and runtime qualification. Model names are design conveniences; they do not imply that Shadow contained modules with those names.
